# Documentation conventions

Use [index.md](index.md) as the canonical navigation. Concept documents use YAML `type`, `title` and `description` strings; the index has no frontmatter. Keep credentials, machine-specific configuration, transient handovers and local runtime state outside tracked documents. Existing application screenshots remain in this directory.
